# 🛒 E-Commerce App (Customer + Admin)

A full-stack **Flutter + Firebase** application with separate **Customer** and **Admin** modules.  
This project demonstrates scalable architecture, clean API integration, and polished UI/UX for mobile commerce.

---

## 🚀 Features

### Customer App
- 🔐 **Authentication**: Secure login & signup with Firebase Auth  
- 📦 **Product Browsing**: View product listings with categories and search  
- 🛍️ **Cart & Checkout**: Add to cart, manage orders, and checkout flow  
- 💳 **Payment Integration**: support for online payments  
- 👤 **Profile Management**: Update user details and view order history  

### Admin App
- 📊 **Dashboard**: Overview of products, orders, and users  
- ➕ **Product Management**: Add, edit, and delete products  
- 📦 **Order Tracking**: Manage customer orders and update statuses

## ⚙️ Installation & Setup

### Prerequisites
- Flutter SDK installed  
- Firebase project configured  
- Node.js for Firebase Functions  

### Steps
1. **Clone the repo**  
   ```bash
   git clone https://github.com/Pov-Phally/EComerce-APP.git
   cd EComerce-APP


- Install dependencies
flutter pub get
npm install --prefix functions
- Configure Firebase
- Update firebase.json and .firebaserc with your Firebase project ID
- Enable Authentication, Firestore, and Storage in Firebase Console
- Run the app
flutter run
